01 / QUICK START

Getting started

Log in using Discord to view communities you manage and access the Destiny dashboard.

  1. Open the dashboard

    Choose Dashboard from the main menu.

  2. Sign in with Discord

    Use Login with Discord and authorize Destiny's requested account and server-list access.

  3. Choose a server

    Under My Servers, select a server where you have the required management permissions. If Destiny is not yet installed, use the invite option.

  4. Explore its controls

    Browse community, moderation, insight and operation tools for your selected server.

03 / AUTHORIZATION

Accounts & permissions

Destiny uses Discord OAuth2 to connect your identity. You will only see servers you own or have permission to manage. Bot installation is separate from logging in.

Not seeing a server?Check whether your Discord account has Manage Server or Administrator permission, and verify that Destiny is installed in the server you want to configure.
04 / PRIVACY

Keep your credentials private

Destiny's backend handles Discord authorization. You should never put your Bot Token, OAuth2 Client Secret or private API keys in a Discord message, browser page or public GitHub repository.

ImportantOnly enter private credentials in your trusted hosting provider's private environment-variable settings. You do not need to share your Discord password with Destiny.
05 / ANSWERS

Frequently asked questions

Do I need to install Destiny before logging in?

No. You can authorize your Discord account and then see the manageable server list. Install Destiny separately in servers where you want to use it.

Why can't I see a server?

You must own the server or have Manage Server or Administrator permission. Ensure you logged in with the correct Discord account.

Are all dashboard settings live?

Not yet. Some panels are previews. Discord login and guild discovery work through the bot backend, while other configuration features are being connected.

How do I return to the homepage?

Use the Destiny eagle in the dashboard sidebar or the Main Menu link at the top of this page.
